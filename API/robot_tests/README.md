# Robot Framework API Test Suite

This folder contains a Robot Framework based API test scaffold with a 3-layer structure (readable test cases -> mapping suites -> keywords/implementation), data parameterization and basic reporting guidance.

## What you get
- `requirements.txt` — Python/Robot dependencies
- `data/` — JSON/YAML files to store credentials, jobs, and input params
- `tests/suites/` — Robot `.robot` suites (middle layer) implementing test cases using keywords
- `resources/` — Implementation keywords (lowest layer) using RequestsLibrary / JSON handling
- `variables/` — central place for environment variables (base URLs, file paths)
- `run_tests.ps1` — convenience PowerShell script to install deps and run tests
- `reports/` — generated by Robot (report.html, log.html, output.xml)

## Setup (local)
1. Ensure Python 3.8+ is installed and is on PATH.
2. From this directory, create a virtual environment (recommended):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Install dependencies:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

4. Run tests and generate reports:

```powershell
robot --outputdir reports tests/suites
# open report
Start-Process .\reports\report.html
```

```
  variables/

  run_tests.ps1
  README.md
  .gitignore
```

## How the 3-layer structure works
1. First layer (readable tests): Robot test cases in `tests/suites` that express test steps using readable keywords.
2. Middle layer: the `.robot` files call keywords (they map steps to keywords).
3. Last layer: `resources/keywords.robot` contains the actual HTTP calls and assertions.

This makes steps readable and reusable while keeping implementation in a single place.

## Jenkins integration
A minimal Jenkins pipeline (Declarative) example is below. It installs dependencies, runs Robot tests, archives the Robot reports and publishes them.

```groovy
pipeline {
  agent any
  stages {
    stage('Prepare') {
      steps {
        powershell 'python -m venv .venv; .\\.venv\\Scripts\\Activate.ps1; python -m pip install --upgrade pip'
        powershell 'python -m pip install -r "${WORKSPACE}\\API\\robot_tests\\requirements.txt"'
      }
    }
    stage('Run Tests') {
      steps {
        powershell 'robot --outputdir API\\robot_tests\\reports API\\robot_tests\\tests\\suites'
      }
    }
    stage('Archive') {
      steps {
        archiveArtifacts artifacts: 'API/robot_tests/reports/**', fingerprint: true
      }
    }
  }
  post {
    always {
      junit allowEmptyResults: true, testResults: 'API/robot_tests/reports/output.xml'
    }
  }
}
```

Notes:
- Use the Jenkins HTML Publisher plugin to display `report.html` and `log.html` in Jenkins UI.
- If you want a custom HTML report generator, you can post-process `output.xml` with `rebot` or third-party tools and publish the generated HTML.

## Custom browser-report guidance
Robot Framework already emits `report.html` and `log.html` (self-contained HTML) that can be opened in Chrome. To generate or customize reports further:
- Use `rebot --report report.html --log log.html output.xml` to post-process
- Consider 3rd-party plugins like ExtendedReport processors or convert `output.xml` to other dashboard formats
